# IMPACT: measurable visual-design constraints (source: [The IMPACT Framework](https://hackernoon.com/the-impact-framework-six-rules-for-better-ai-generated-designs))
Vague adjectives ("clean", "modern", "professional", "make it pop") resolve to the training average and invite "add more". When UI work has no design system, or a DESIGN.md is being distilled, state each rule as a measurable fact. Optional guidance, not a gate: lite / `/flow-quick` / no-UI work skips it; a small UI change cites only the rules it touches. Pin structure, leave 1–2 decisions open; never paste builder code into a project.
- **Structure first (fix these before surface).** **I Importance**: name what reads 1st/2nd/3rd and what stays quiet; headline ≥ 3× the next level (below ~2:1 feels flat). **M Margins**: minimum margin as % of width (default ≥ 10% each side for compositions; a spacing-scale step for app UI); tight inside groups, open between groups. **A Alignment**: one grid, one alignment rule, flush-left over centering everything; almost-aligned is worse than unaligned.
- **Surface.** **P Palette**: ≤ 3 colors with roles at ~60/30/10 (anchor = background, support = text/structure, accent = the one thing to find); only the accent is saturated and appears once or twice. No-brand defaults: Calm #F8F7F4/#2B2B2B/#3D5A80, Warm #FDF6EC/#3B2F2F/#C97B63, Minimal #F2F2F2/#1A1A1A/#7A9E7E. **C Contrast**: one dominant element; dark-on-light or light-on-dark, never mid-on-mid; squint test; UI text meets WCAG 4.5:1 body / 3:1 large. **T Typography**: ≤ 2 typefaces (one family in two weights is often better); name real fonts and weights (e.g. Inter 700/400, headline ≈ 3× body).
- **Exclusions + lint.** Always end the spec with AVOID and 4–8 items for the medium (gradients, drop shadows, glow, texture/noise, decorative borders, stock-photo people, script/display fonts). Translate adjectives: clean → flat background, generous whitespace, 2 colors, no ornament; modern → name an era (Swiss International, Scandinavian minimal); professional → restrained palette, left-aligned, one accent; bold → heavy weight, big size jump, one dominant element; pop → larger, higher contrast, or the only saturated element. Lint built UI in that order: reading order obvious in 1s, margins on every edge, ≤ 3 colors with one saturated accent, one left edge, no mid-on-mid, ≤ 2 faces with exact strings, no excluded effect crept back.
